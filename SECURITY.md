# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do NOT open a public issue.**
2. Email: **security@tempus-engine.dev** (or open a GitHub Security Advisory).
3. Include: affected version, steps to reproduce, and potential impact.
4. You will receive an acknowledgment within **48 hours**.

## Scope

- Tempus Engine Rust crate (`tempus-engine`)
- Python bindings
- WASM bindings
- CI/CD pipeline definitions

## Out of Scope

- The underlying [jsonlogic-fast](https://github.com/JPatronC92/First-T-Engine) library (report there instead)
- Rule logic authored by users of the engine
